The Linux terminal runs in the Android app. It is not available in a web browser.

Install Linux

Downloads a minimal Alpine Linux root filesystem (about 4 MB) into the app's private storage. Packages come from the Alpine mirror with apk when you need them.

Projects

Repositories are cloned into /root/projects inside Linux. A token lists your private repositories. It is stored encrypted on this device, and git receives it through an environment variable.
